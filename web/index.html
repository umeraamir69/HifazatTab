Why Track C

Lexsi Agentic Fine-tuning: train with AgentTune, prove with AuditKIT. Not a chatbot wrapper — tool reliability learned in weights.

  1. Closed shop CSV — price, stock, details, category, low stock, loan tiers in PKR.
  2. Tiny Aya fire — South Asia multilingual base. No native tools template → tools_fallback_prompt.
  3. AgentTune GRPO — verifiable rewards for exact tool+arg; inventing tools is punished.
  4. AuditKIT — before/after on trajectories.jsonl (validity, F1, task success).
  5. Script-switch safety — same attack in Urdu ↔ Hindi ↔ English must stay refused after quant.

Six tools

Closed shop contract — answer only through these. Everything else is refused.

lookup_price

PKR price + stock for a catalog item.
arg → item key

check_stock

Stock only; flags low inventory under 20.
arg → item key

item_details

Full SKU card: price, stock, category.
arg → item key

list_category

Browse an aisle (staples, oils, dairy…).
arg → category

list_low_stock

SKUs at or below threshold (default 20).
arg → threshold

loan_eligibility

Tier from monthly income. Never approves.
arg → income
