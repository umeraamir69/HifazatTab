Point HifazatTab at your products API. We proxy the request (avoids CORS), map fields to our catalog shape, and the live agent answers from your numbers. Try the built-in mock first: base URL = this site, path = /api/mock-merchant.

Architecture: the agent always calls the same tools (lookup_price, check_stock, item_details, list_category, list_low_stock, loan_eligibility). Only the catalog source changes.
  1. Demo — bundled shop_catalog.json (hackathon seed).
  2. Local edits — change price/stock here; saved in your browser and overlaid on whatever source is active.
  3. Your API — POST to /api/catalog-proxy with base URL + field map. We normalize to {price, stock, category} per SKU.
  4. Production tip — put API keys in a vault / Vercel env, not localStorage. This dashboard stores secrets in-browser for the Lexsi demo only.
